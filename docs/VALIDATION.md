- Worktree 支持新建分支 / 工作树、锁定 / 解锁、独立标签打开、移除干净工作树和清理缺失登记。切换 / 删除 / 改写分支检查其他工作树占用。子模块支持添加、初始化 / 精确版本更新、递归更新、URL 同步及 gitlink 暂存；拒绝覆盖脏子仓库，网络任务使用现有仓库独立队列和取消控制。
- LFS 本地功能原生计算 SHA-256、缓存并提交标准指针，checkout / discard / rebase / stash 后展开经过校验的对象。缺失对象保留指针，腐坏对象拒绝覆盖；不支持部分暂存，Stash 前要求暂存 LFS 编辑。远程传输直接启动官方 git-lfs，不经过 Bash；普通 Push 先上传 LFS 对象，失败不更新 Git refs。扫描先读取对象大小，只加载指针大小的 blob，并支持取消和错误传播。取消 Unix 进程组及子进程，错误输出有上限。
