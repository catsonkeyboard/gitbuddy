## 本轮裁定

- Ruling: Worktree move 对含子模块的工作树保持拒绝，与本机 Git 官方 git-worktree 手册一致；避免改写共享子模块元数据。代价是用户需保持原位置或按 Git 提供的外部迁移方式处理后再修复登记。
- Ruling: 补丁恢复沿用精确路径拼写、预期内容和 Git 模式的状态判定；它不证明 inode 来源，也无法识别外部程序恰好重建相同字节 / 模式时的任意额外元数据变化。应用时禁止覆盖既有目标，未知内容 / 类型 / 拼写则拒绝恢复；仍需协调外部写入。
